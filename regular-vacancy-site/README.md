# 슈퍼차일드 정규반 자리 현황 프로토타입

기존 시간표와 분리된 공개 페이지 프로토타입입니다.

## 현재 동작

- 가경점/용암점 선택
- 월요일~토요일 선택
- 평일 2시~8시, 토요일 9시~2시 표시
- 시간별 `자리 있음` / `자리 없음` 표시
- 전화 상담 연결
- 카카오톡 링크는 `config.js`에 지점별 URL을 입력한 뒤 활성화
- 공개 빈자리 API를 15초마다 다시 확인
- 로컬에서 API가 아직 배포되지 않은 경우에만 `data/availability.json` 샘플 사용

## 데이터 원칙

공개 페이지에는 원생명, 전화번호, 선생님명, 정확한 인원수를 넣지 않습니다.
Cloud Function이 시간표 변경을 감지해 `publicRegularAvailability`에
개인정보 없는 지점별 요약을 저장합니다. 공개 페이지는
`regularAvailability` API를 통해 이 요약만 읽습니다.

집계 기준은 2026년 9월 운영기간 시작일입니다.

- `~부터`: 시작일이 기준일 이전 또는 당일이면 사용 중
- `~까지`: 종료일 당일까지 사용 중
- 보강, 샘플, 방학특강은 정규반 자리 집계에서 제외
- 일반반 5칸, 엘리트/마스터 계열은 실제 8칸 기준
- 선생님 미배정 칸과 비활성 칸은 빈자리로 공개하지 않음

`http://127.0.0.1:8000/regular-vacancy-site/`
