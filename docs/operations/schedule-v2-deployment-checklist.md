# Schedule V2 배포 체크리스트

## 배포 전

- [ ] 운영시간 밖이거나 데스크와 편집 중단 시간을 합의했다.
- [ ] 승인된 Git 커밋 SHA를 기록했다.
- [ ] 배포할 작업 폴더에 예상하지 않은 변경 파일이 없다.
- [ ] `npm.cmd run test:unit` 결과가 실패 0건이다.
- [ ] Firestore 규칙 보안 검사와 Functions API 검사가 통과했다.
- [ ] 가경점과 용암점의 현재 mode, generationId, epoch, revision을 기록했다.
- [ ] 마지막 검증 완료 generationId를 기록했다.
- [ ] 공식 rollback 동작과 담당자를 확인했다.

## 단계 전환 공통 확인

- [ ] V1 미러 복구 `pending = 0`, `processing = 0`, `error = 0`
- [ ] 학부모 요청 복구 `pending = 0`, `processing = 0`, `error = 0`
- [ ] 가경점 V1/V2 불일치 0건
- [ ] 용암점 V1/V2 불일치 0건
- [ ] 정규반과 방학특강 동시 수정 시나리오 통과
- [ ] 서로 다른 출석 동시 체크 시나리오 통과
- [ ] revision 증가만으로 화면 새로고침 안내가 발생하지 않음
- [ ] 진단 정보에 이름, 전화번호, 요청 본문이 없음

## 전환 순서

- [ ] `v1 -> shadow`
- [ ] Shadow 상태에서 두 지점 복사 및 불일치 0건 확인
- [ ] `shadow -> verify`
- [ ] Verify 상태에서 원생 이동, 결석·보강, 출석부 저장 확인
- [ ] `verify -> v2-read`
- [ ] V2 Read 상태에서 다른 기기 동기화와 V1 복구 미러 확인
- [ ] `v2-read -> v2`

## V2 Read 필수 실사용 점검

- [ ] 가경점 정규반 원생 등록·이동
- [ ] 가경점 방학특강 원생 등록·이동
- [ ] 용암점 정규반 원생 등록·이동
- [ ] 용암점 방학특강 원생 등록·이동
- [ ] 퇴원 또는 제외 예약
- [ ] 결석 등록·취소
- [ ] 일반·방특·의무 보강 등록·취소
- [ ] 정규반 출석 및 일괄 출석
- [ ] 방학특강 출석 및 일괄 출석
- [ ] 출석 손님 등록·수정·삭제
- [ ] 출석 스냅샷 생성 및 과거 날짜 조회
- [ ] 탭 전환 중 저장 결과 유지
- [ ] 서로 다른 원생 동시 저장 결과 모두 유지
- [ ] 같은 원생 동시 저장 시 덮어쓰기 없이 충돌 안내

## 배포 후

- [ ] 첫 30분 동안 5분 간격으로 복구 및 불일치 건수를 확인했다.
- [ ] 저장 성공 후 다른 기기에서 같은 결과를 확인했다.
- [ ] 다음 운영일에 전날 출석부와 스냅샷을 다시 열어 확인했다.
- [ ] 최종 mode, generationId, epoch, revision을 기록했다.

## 즉시 되돌리기

아래 항목이 하나라도 발생하면 편집을 멈추고 runbook의 되돌리기 절차를 따른다.

- [ ] 예상하지 않은 mode, generationId, epoch 변경
- [ ] 불일치 1건 이상
- [ ] 복구 error 1건 이상 또는 대기 건수 지속 증가
- [ ] 원생·출석·결석·보강 저장 결과 누락 또는 중복
- [ ] 여러 계정에서 반복되는 권한 오류
- [ ] 개인정보가 진단 로그에 노출됨
