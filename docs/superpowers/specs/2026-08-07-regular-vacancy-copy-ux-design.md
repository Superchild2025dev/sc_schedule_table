# 정규반 빈자리 안내 페이지 문구 및 UX 정리

## 목표

정규반 빈자리 페이지가 참고용 정보라는 점을 사용자가 시간표를 보기 전에 이해하도록 하고, 실제 화면 내용과 맞지 않는 표현을 정리한다.

## 변경 범위

- 시간표 바로 위에 빈자리 현황이 참고용이며 변동될 수 있다는 안내를 배치한다.
- 정확한 등록 가능 여부는 해당 지점 문의를 통해 확인하도록 안내한다.
- `정규반 전환 안내`를 `정규반 자리 안내`로 변경한다.
- `등록 가능한 시간`을 `요일별 자리 현황`으로 변경한다.
- 고정된 연월이 들어간 영웅 영역 설명을 `정규반 등록 가능 시간을 확인하세요.`로 변경한다.
- 기존 등록 상태 색상, 문의 버튼, 담당 선생님 확인 기능과 데이터 처리 방식은 유지한다.

## 화면 구성

안내 문구는 지점·요일 선택 영역과 시간표 사이에 한 줄 안내 영역으로 표시한다. 하단에 있던 중복 안내는 제거하여 같은 내용을 두 번 보여주지 않는다.

## 검증

- 데스크톱과 모바일에서 안내 문구가 잘리지 않는다.
- 지점 및 요일 선택, 시간표 펼침, 문의 링크가 기존과 동일하게 동작한다.
- 자동화된 공개 페이지 검사에서 필수 문구와 기존 보안 속성이 유지된다.
